GLOBAL ROUTES TYCOON

Kebijakan Privasi

Terakhir diperbarui: 30 Oktober 2026

Kebijakan ini menjelaskan cara aplikasi Global Routes Tycoon menangani informasi pengguna. Aplikasi ini merupakan game simulasi manajemen rute transportasi yang berjalan secara lokal di perangkat.

1. Informasi yang dikumpulkan

Aplikasi tidak meminta nama, alamat, nomor telepon, kontak, lokasi, foto, atau informasi akun. Aplikasi tidak mengumpulkan atau mengirimkan data pribadi maupun data aktivitas permainan ke server pengembang.

2. Penyimpanan progres permainan

Progres permainan seperti saldo, armada, rute, dan perkembangan perusahaan disimpan secara lokal pada penyimpanan aplikasi di perangkat pengguna. Data tersebut digunakan hanya untuk melanjutkan permainan. Data tidak disinkronkan ke cloud dan tidak dibagikan kepada pengembang atau pihak lain.

3. Iklan dan layanan pihak ketiga

Versi aplikasi ini tidak memuat iklan, SDK analitik, layanan pelacakan, maupun integrasi login pihak ketiga.

4. Izin perangkat dan koneksi internet

Game dikemas bersama file permainan dan dirancang dapat dimainkan secara offline. Versi ini tidak meminta izin sensitif perangkat dan tidak memerlukan koneksi internet untuk fitur permainan.

5. Penghapusan data

Pengguna dapat menghapus progres melalui menu Pengaturan permainan lalu memilih Reset progress. Menghapus data aplikasi atau menghapus instalasi aplikasi juga akan menghapus data lokal yang tersimpan.

6. Privasi anak

Aplikasi ini tidak secara sengaja mengumpulkan informasi pribadi dari anak-anak maupun orang dewasa. Aplikasi tetap harus diberi target usia dan rating konten yang sesuai saat pengaturan di Google Play Console.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur atau cara kerja aplikasi berubah. Versi terbaru akan dipublikasikan pada halaman kebijakan privasi aplikasi.
